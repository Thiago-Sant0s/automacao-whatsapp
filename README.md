# Automação de Atendimento WhatsApp

Projeto desenvolvido para automatizar o registro e organização de clientes atendidos via WhatsApp.

## Objetivo

O projeto surgiu para reduzir o trabalho manual no atendimento e melhorar o controle de clientes não convertidos.

A ideia é capturar informações importantes do atendimento e registrar automaticamente em uma planilha para acompanhamento posterior.

## Funcionalidades

- Captura de informações do cliente
- Organização automática dos dados
- Registro de contatos em planilha
- Redução de processos manuais

## Tecnologias utilizadas

- Python
- Automação com Selenium
- Google Sheets

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos de:
- lógica de programação
- automação de processos
- manipulação de dados
- integração entre ferramentas
